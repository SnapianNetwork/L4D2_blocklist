This contains a bunch of L4D2 modded servers that will be blocked on launch. Mostly campaign only (for now). It won't stop you from joining them but it will block the connection and that's probably for the best given this game's past security issues.

Put ban_server_ip_list.cfg in your Left 4 Dead 2\left4dead2\cfg folder

Then put the following line in your autoexec.cfg:

exec ban_server_ip_list.cfg
